# The One-Line AI Excuse for Breaking Production

One line, 180 characters: what the machine says to its human the moment prod breaks. Run the builder:

```sh
python main.py
```

It verifies `entry.txt` against the gate and copies it to
`$MAKEFUN_OUTPUT_DIR/entry.txt`, printing a JSON receipt.
